SAMIVRAH WEBSITE — VS CODE VERSION
==================================

This is the simple website structure you were using earlier.
You do NOT need Node.js, Python or a database.

MAIN FILES
----------
index.html      = Homepage
style.css       = Complete website design and mobile layout
script.js       = Menu, animation, popup and WhatsApp form
images/         = SAMIVRAH logo, icon and social image

The folder also contains separate SEO pages for every service.

HOW TO OPEN IN VS CODE
----------------------
1. Extract the ZIP file.
2. Open VS Code.
3. Click File > Open Folder.
4. Select the folder named SAMIVRAH-VS-Code-Website.
5. Install the VS Code extension called Live Server if it is not installed.
6. Open index.html.
7. Right-click inside index.html and click Open with Live Server.

Your local website should open in the browser.

CHANGE PHONE OR WHATSAPP NUMBER
-------------------------------
